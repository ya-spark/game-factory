# Balloon pop (game package `game_balloon_pop`)

Status: BUILT. The game lives once in `game-factory/games/balloon_pop/` (SH1, owner 2026-11-21); apps and the web list it in their registry and bring content, theme and services. Nothing is copied. Rules in `lib/src/rules/`, the screen in `lib/src/balloon_pop_screen.dart`, test IDs in `GameIds` (game_core) and `lib/src/balloon_pop_ids.dart` where the game has its own. It asks its container only through `GameHost` (`game_core/lib/host`).

The text below was collected from the apps' docs when the game moved; refine it here from now on (this file is the only copy of the game's behaviour).

## How to play (as shown to the child)
- Read the question, then pop the balloon with the right answer.
- Balloons float up the screen. Younger levels have no timer.
- Tips:
  - Read every balloon before you pop one.
  - Take a moment if the question is tricky.

## Look: sprites (owner, 2026-11-21)
The balloons are sprite images (`assets/balloon_<colour>.png`, generated by the owner with Figma's AI image tool, cut and
background-removed; rows in `assets/LICENSES.md`, no text, no people): red, blue, yellow, purple and orange cycle across the
balloons; a balloon popped wrong turns grey; the right one turns green when it is shown. The answer text sits on the balloon
(white on red, blue and purple; dark ink on the others). The sprites are loaded with `package: 'game_balloon_pop'`, so every
container gets them with the game. Reduced motion and sizes are as before.
